# 推荐高分知识条目

## 使用场景

- 用户要求推荐高分文章 / 优质条目时。
- 用户输入 `/top` 或自然语言"高分""评分最高""推荐几篇"时。
- 需要快速了解当前知识库中评分最高的条目时。

## 执行步骤

1. **扫描知识条目目录**：使用 Glob 匹配 `knowledge/articles/kb-*.json`（跳过 `index.json`），获取全部知识条目文件路径。

2. **逐文件读取并解析**：读取每个 JSON 文件，提取以下字段：
   - `article_id` -- 条目标识
   - `title` -- 标题
   - `score` -- AI 评分（1-10 整数），字段缺失或为 null 时视为 0
   - `summary` -- 中文摘要
   - `tags` -- 标签数组
   - `source_url` -- 原始链接
   - `collected_at` -- 采集时间
   - `category` -- 分类

3. **排序**：按 `score` 降序排列。评分相同时，按 `collected_at` 降序（新的优先）。

4. **取 Top 5**：取排序后的前 5 条。若总条目不足 5 条则全部返回。

5. **格式化输出**：按下方输出格式渲染为 Markdown，输出给用户。不写文件。

## 注意事项

- **只读操作**：本技能不修改任何文件，仅读取和展示。
- **字段名**：评分字段为 `score`（整数 1-10），不是 `relevance_score`。字段缺失时按 0 分处理。
- **禁止编造**：展示的标题、摘要、评分须严格来自 JSON 文件，禁止虚构或改写。
- **禁止裸 `print()`**：一律使用 `logging`。
- **类型注解**：如编写辅助函数，须有完整类型注解。
- 完整规范见项目根目录 `AGENTS.md` §4（知识条目 JSON 格式）、§8（红线）。

## 输出格式

输出为 Markdown 字符串，直接展示给用户，不写文件。格式如下：

```markdown
🏆 高分推荐 Top 5

1. **[条目标题](source_url)**
   评分: 9/10 | 日期: 2026-07-30 | #tag1 #tag2 #tag3
   摘要: 中文摘要内容...

2. **[条目标题](source_url)**
   评分: 8/10 | 日期: 2026-07-30 | #tag1 #tag2
   摘要: 中文摘要内容...

...（共 5 条）
```

### 字段说明

| 展示字段 | 来源 JSON 字段 | 说明 |
| --- | --- | --- |
| 标题 | `title` | 条目标题 |
| 链接 | `source_url` | 原始链接，作为 Markdown 超链接 |
| 评分 | `score` | 1-10 整数，缺失为 0 |
| 日期 | `collected_at` | 取前 10 位（YYYY-MM-DD） |
| 标签 | `tags` | 取前 3 个，以 `#` 前缀展示 |
| 摘要 | `summary` | 中文摘要原文 |
