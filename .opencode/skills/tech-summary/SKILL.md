# 技术内容深度分析总结

## 使用场景

- 分析 Agent 需要对采集阶段产出的原始内容进行深度分析时。
- 需要为每条候选条目生成中文摘要、技术亮点、评分与标签建议时。
- 需要从一批采集中发现共同主题与新兴概念趋势时。

## 执行步骤

1. **读取最新采集文件**：读取 `knowledge/raw/` 下最新的采集文件（如 `github-trending-YYYY-MM-DD.json` 或 `<article_id>.md`），解析出待分析的条目列表。若采集文件为 JSON，按 `items` 数组逐条处理；若为 Markdown 原始文件，按文件头元信息与正文解析。

2. **逐条深度分析**：对每条条目执行以下分析--
   - **摘要**：撰写 ≤50 字中文摘要，包含核心内容与关键特性，基于原文事实，禁止编造或夸大，保留专有名词英文原名。
   - **技术亮点**：提炼 2-3 条亮点，每条一句话，须含具体数据/性能指标/创新点，用事实说话，禁止泛泛而谈。
   - **评分**：按下方评分标准打 1-10 分，并附评分理由（一句话说明为何给该分数）。
   - **标签建议**：建议 3-8 个小写英文标签（如 `llm`、`rag`、`inference`），至少含一个技术领域标签和一个细分方向标签；通过 Grep 检查已有条目标签以保持词汇一致。

3. **趋势发现**：跨条目横向分析--
   - **共同主题**：识别本批中多个条目共同涉及的技术主题（如多个项目都涉及 KV Cache 优化、多个论文都讨论 Agent 工具调用）。
   - **新概念**：标注本批中首次出现的 emerging 概念/技术（如新模型架构、新评测基准、新框架范式），简述其为何值得关注。

4. **输出分析结果 JSON**：将逐条分析与趋势发现合并为分析结果 JSON，交由整理 Agent 落盘。本技能不直接写文件。

## 评分标准

| 分数区间 | 等级 | 判定标准 |
| --- | --- | --- |
| 9-10 | 改变格局 | 开创性模型/框架发布、颠覆性技术突破，可能重新定义领域方向 |
| 7-8 | 直接有帮助 | 实用工具/框架/教程，开发者可直接上手应用，解决明确痛点 |
| 5-6 | 值得了解 | 有参考价值的技术动态/论文，拓宽视野但非即时可用 |
| 1-4 | 可略过 | 信息量低、重复度高、或与核心领域关联较弱 |

## 注意事项

- **高分限额**：单批 15 个项目中，9-10 分条目不超过 2 个。若候选高分超过 2 个，择优保留信息量最大、原创性最高的 2 个，其余降档至 7-8 分并说明理由。
- **摘要长度**：单条摘要 ≤50 字（中文），超出须精简。
- **亮点须具体**：每条亮点须含具体数据/性能指标/创新点，禁止"性能优异""设计优雅"等空泛表述。
- **标签一致**：相同技术主题须复用已有标签，通过 Grep 检查 `knowledge/articles/` 中已有条目的标签词汇。
- **不编造**：所有摘要、亮点、评分理由须严格基于原文事实，禁止虚构项目、论文或数据。
- **不落盘**：分析 Agent 为只读权限，分析结果以内存 JSON 交给整理 Agent，不直接写文件。
- **密钥安全**：`LLM_API_KEY` 从环境变量读取，禁止硬编码，禁止记入日志。
- **禁止裸 `print()`**：一律使用 `logging`。
- **类型注解**：所有公开函数须有完整类型注解。

完整规范见项目根目录 `AGENTS.md` §6.2-6.4（标题/摘要/标签规范）、§8（红线）。

分析结果以内存 JSON 交给整理 Agent，结构如下：

```json
{
  "analyzed_at": "2026-07-27T08:05:00Z",
  "items": [
    {
      "name": "vllm-project/vllm",
      "title": "vLLM：高吞吐量 LLM 推理引擎",
      "summary": "vLLM 通过 PagedAttention 优化 KV Cache 内存管理，推理吞吐量显著提升。",

```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `analyzed_at` | string | 分析完成时间（ISO 8601 UTC） |
| `items` | array | 逐条分析结果 |
| `items[].name` | string | 条目标识（仓库名/文章名） |
| `items[].title` | string | 中文标题，保留专有名词英文原名 |
| `items[].summary` | string | 中文摘要，≤50 字 |
| `items[].highlights` | string[] | 2-3 条技术亮点，每条含具体数据 |
| `items[].score` | integer | 1-10 评分 |
| `items[].score_reason` | string | 评分理由，一句话 |
| `items[].tags` | string[] | 3-8 个小写英文标签 |
| `trends.common_themes` | string[] | 本批共同技术主题 |
| `trends.emerging_concepts` | string[] | 本批新概念/新兴技术 |
